# Chat room (catalog #1132)

Socket.IO chat from Peter O'Hanlon’s *Advanced TypeScript Programming Projects* (Chapter 6). TypeScript server; in-memory messages instead of MongoDB for local runs.

## Run (port 3029)

```powershell
Set-Location "c:\Users\emmak\Desktop\Content\CodingProjects\PortProjects\demos\chat-room\web"
npm install
npm run dev
```

Open http://localhost:3029 — join the same room name in two tabs to test.
