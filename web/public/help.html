How to use the chat

Rooms

Enter a display name and room name, then Join room. Everyone using the same room name on this server sees the same messages.

Participant markers

Each display name gets a stable colored symbol automatically (same name always gets the same marker). Messages show the symbol and name so you can tell speakers apart in a busy room.

History

When you join, the server sends prior messages for that room (stored in memory for this demo session).

Presence

After joining, your display name is announced on an internal presence channel so you can see who connected (same behavior as the reference app, without a database).
